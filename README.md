# 🚀 Cloudflare WARP + Zapret

Готовые сборки **Cloudflare WARP + Zapret** для Windows с подготовленными конфигурациями, актуальными списками доменов и IP, а также дополнительными настройками для стабильной совместной работы.

🎥 **Мой YouTube:** https://www.youtube.com/@Maktrixs
🛡️ **Основа проекта:** https://github.com/Flowseal/zapret-discord-youtube
⚙️ **Оригинальный бинарный пакет:** https://github.com/bol-van/zapret-win-bundle

---

## 🌐 О проекте

Этот репозиторий предназначен для публикации **готовых сборок Zapret**, подготовленных для использования совместно с **Cloudflare WARP**.

Проект больше не ориентирован на автоматическую сборку и самостоятельную настройку пользователем.

В каждом релизе публикуется готовый **ZIP-архив**, который необходимо распаковать в отдельную папку. После распаковки можно запускать встроенный менеджер и подбирать подходящую конфигурацию.

> **Zapret уже входит в сборку. Отдельно устанавливать его не требуется.**

> **Cloudflare WARP устанавливается отдельно.**

---

## ✨ Что входит в сборку

* 🚀 Готовая сборка **Zapret** (`winws.exe`).
* ⚙️ Подготовленные конфигурации для работы с Cloudflare WARP.
* 🌐 Обновлённые списки доменов (`hostlist`).
* 📡 Обновлённые списки IP (`ipset`).
* 📝 Дополнительные пользовательские списки.
* 🔧 Оптимизированные параметры `winws`.
* 🧪 Автоматическое тестирование доступных стратегий.
* 📁 Менеджер конфигураций и профилей.
* 🛠️ Исправления и дополнительные улучшения, появляющиеся в новых релизах.

## 📥 Установка

### 1. Скачайте релиз

Скачайте актуальный **ZIP-архив** из раздела Releases.

### 2. Распакуйте архив

Распакуйте **весь архив** в отдельную папку.

> ⚠️ Не запускайте файлы непосредственно из ZIP-архива.

Рекомендуется использовать простой путь, например:

```text
C:\Zapret-WARP\
```

### 3. Установите Cloudflare WARP

Cloudflare WARP необходимо установить отдельно.

🌐 Официальный сайт: https://one.one.one.one/

### 4. Запустите менеджер

После распаковки откройте папку сборки и найдите:

```text
#Запуск_Менеджера.bat
```

Нажмите по файлу **правой кнопкой мыши** → **«Запуск от имени администратора»**.

В открывшемся меню выберите:

```text
1 - Запустить автотест
```

Менеджер самостоятельно проверит доступные стратегии и параметры, после чего подберёт подходящую конфигурацию для вашего подключения.

## ⚙️ Как это работает

Схема использования:

```text
ZIP-архив
    ↓
Распаковать
    ↓
Установить Cloudflare WARP
    ↓
Запустить #Запуск_Менеджера.bat
    ↓
Запустить автотест
    ↓
Проверка стратегий
    ↓
Создание рабочего профиля
    ↓
Cloudflare WARP + Zapret
```

Сборка является **портативной** - отдельный установщик Zapret и создание ярлыков на рабочем столе не требуются.
