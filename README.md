# 🚀 Cloudflare WARP + Zapret

Готовая сборка Cloudflare WARP + Zapret для Windows с уже настроенными конфигурациями, обновлёнными списками доменов и IP, а также дополнительными улучшениями для стабильного обхода блокировок.

⚙️ **Оригинальный бинарный пакет:** https://github.com/bol-van/zapret-win-bundle

---

## 🌐 О проекте

Данный репозиторий больше не ориентирован на автоматическую сборку и настройку.

Теперь основная цель проекта — публикация **готовых сборок**, которые можно скачать и сразу использовать без дополнительной настройки.

Каждый релиз включает в себя актуальные изменения, проверенные конфигурации, обновлённые списки доменов и IP, а также другие улучшения, направленные на повышение стабильности работы Cloudflare WARP и Zapret.

---

## ✨ Что входит в сборку

* Готовая конфигурация Cloudflare WARP + Zapret.
* Обновлённые списки доменов (`hostlist`).
* Обновлённые списки IP (`ipset`).
* Дополнительные пользовательские списки.
* Оптимизированные параметры `winws`.
* Исправления и улучшения конфигураций.
* Другие изменения, появляющиеся в новых релизах.

## 📖 Использование

> [!IMPORTANT]
> **❗ ВАЖНО**
>
> Все файлы с расширением `.bat` необходимо запускать **от имени администратора**.
>
> Для этого:
> 1. Нажмите правой кнопкой мыши по нужному файлу.
> 2. Выберите **«Запуск от имени администратора»**.
